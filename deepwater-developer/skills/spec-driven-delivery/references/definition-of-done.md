# Definition of done

A feature is complete only when:

- [ ] The GitHub issue and specification agree.
- [ ] Existing behavior was inspected and classified (REUSE / EXTEND / WRAP / REFACTOR / REPLACE / NEW).
- [ ] The bounded context and data owner are documented.
- [ ] One application use case owns the workflow.
- [ ] Required interfaces call the same use case.
- [ ] Domain code has no framework dependency.
- [ ] Outbound dependencies are behind narrow ports.
- [ ] Acceptance, unit, contract, security, and integration tests are present as applicable.
- [ ] AI output is schema-validated and evaluated when applicable.
- [ ] Timeouts, errors, retries, and idempotency are reviewed.
- [ ] Logs and audit events contain no sensitive values.
- [ ] Formatting, static analysis, architecture tests, and required scans pass.
- [ ] Documentation, migration, deployment, and rollback plans are complete.
- [ ] No unrelated or generated files are included.
- [ ] No commit or push was performed without explicit instruction.
